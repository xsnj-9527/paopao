========================================================
  泡泡 · 应用使用文档
  （DeepSeek AI 聊天搭子 · v1.0.0）
========================================================

一、应用简介
--------------------------------------------------------
「泡泡」是一款基于 DeepSeek 大模型的 AI 聊天搭子应用。
你可以创建多个性格各异的虚拟角色（萌娃/同龄搭子/长辈），
与它们单聊或组建群聊，角色会记得你告诉它的事，像真朋友
一样陪伴你。

版本：1.0.0（2026-08-13）
运行环境：Android 8.0 及以上


二、安装说明
--------------------------------------------------------
1. 将 APK 文件（泡泡-v1.0.0.apk）传输到手机
2. 点击安装，若提示"未知来源"，按提示允许安装
   （设置 -> 安全 -> 允许安装未知应用）
3. 首次打开会请求通知权限，请允许（提醒功能需要）


三、首次使用
--------------------------------------------------------
1. 打开应用 -> 进入【连接设置】
2. 填入 DeepSeek API Key（还没 Key？看下方【获取 API Key
   快速指南】，约 10 分钟搞定）
3. 可选调整：模型（默认 deepseek-v4-flash）、温度、思考模式
4. 保存后进入首次向导：选择你的性别、想要的角色感觉、
   兴趣爱好（可自定义输入）-> 生成第一个角色
5. 回到【我的】- 点头像卡片，完善个人资料（姓名/职业/简介），
   角色会读取这些信息更了解你

【获取 API Key 快速指南】
（手把手版，完全没接触过 AI 也能搞定，约 10 分钟）

- API Key 是什么：一张"门禁卡"。泡泡本身不会思考，它拿
  这张卡去 DeepSeek 借大脑来回答问题。卡免费办，使用要
  少量充值。
- 操作步骤：
  ① 手机浏览器打开 platform.deepseek.com
  ② 注册（手机号/邮箱，收验证码）或直接登录
  ③ 左侧菜单找【API Keys】-> 点【创建 API Key】
  ④ 名称随便填（如 paopao），点创建
  ⑤ 复制以 sk- 开头的那串字符
     ⚠️ 它只会完整显示这一次！立刻保存到备忘录，
     关掉页面就再也看不到了！没复制就删掉旧的
     重新创建一条即可
  ⑥ 去【充值】充 ¥10 左右（微信/支付宝），1-2 分钟生效
  ⑦ 回到泡泡【连接设置】，粘贴 Key，点保存
- 费用：日常聊天极便宜，¥10 能用很久（正常聊一个月
  可能花不到 ¥1）
- 注意：Key 相当于钱包密码，千万别发给别人！


四、界面导航
--------------------------------------------------------
底部三个标签页：
【聊天】- 会话列表（单聊 + 群聊），按最近聊天排序
【通讯录】- 好友列表（按姓名拼音首字母排序），可搜索、
           新建角色、新建群聊
【我的】- 个人中心：资料 / 头像 / 外观 / 设置 / 便签 /
          记忆 / 收藏


五、聊天功能
--------------------------------------------------------
1. 单聊
   - 点击消息左侧角色头像 -> 角色主页（背景/签名/标签）
   - 角色主页底部【修改】可编辑：头像、聊天背景、主页背景、
     签名、个性标签、角色设定（名字/心情/外貌/背景经历等）
   - 顶部标题点头像同样可进入角色主页

2. 群聊
   - 通讯录 ->「＋新建群聊」-> 起群名、勾选成员（2 人以上）
   - 群内每个成员保持各自性格，发言标注【名字】
   - 每条消息上方显示发言者名字，左侧是发言者头像
   - 点击群成员消息头像 -> 该成员主页（含【私聊】按钮）
   - 群右上角 ⋮ -> 群设置：查看成员（点击跳私聊）、改群名、
     群背景、解散群聊
   - 长按群聊 -> 清空聊天记录（不解散群）

3. @ 功能（群聊）
   - 输入框左侧 @ 按钮 -> 选择「全体成员」或具体成员
   - 被 @ 的成员优先回应

4. 消息长按操作
   - 复制 / 引用（回复时带原文）/ 撤回（自己的消息，
     3 分钟内）/ 删除 / 多选
   - 多选后可：转发到其他会话 / 导出成文件分享 /
     收藏（我的 -> 收藏查看）
   - 长按菜单为右侧浮层，点菜单外任意处关闭

5. 语音类：暂无（已移除）


六、记忆系统（核心特色）
--------------------------------------------------------
1. 显式记忆：聊天中说「记住我养猫了」，角色会调用工具
   记下来并确认
2. 自动抽取：每 10 轮自动提炼对话中的关键事实（隐私模式
   下关闭）
3. 记忆按角色隔离：每个角色只记得你亲口告诉 TA 的事；
   群聊中讨论的事，群内所有成员都会记住（私聊时也记得）
4. 记忆管理：【我的】->【记忆】查看/添加/固定/删除/清空，
   还包含日历日记和行为准则


七、提醒与便签（工具）
--------------------------------------------------------
1. 提醒：说「帮我设一个 3 分钟后的提醒，提醒我喝水」
   -> 角色调用提醒工具 -> 到点收到通知
2. 便签：说「帮我记个便签：明天买猫粮」
   -> 我的 ->【便签】查看和删除
3. 时间：问「现在几点了」角色会调用工具获取准确时间


八、个性化功能
--------------------------------------------------------
1. 角色主页：背景图（默认按年龄段渐变，可自定义）、
   自动生成签名（符合角色设定）、个性标签
   （AI 生成或自定义）
2. 情绪闪念：你发情绪化的消息时，等待回复期间背景会有
   呼吸光晕（开心暖黄 / 焦虑冷蓝 / 生气红色）
3. 日历日记：每天自动生成一篇 200 字以内的第三人称日记，
   角色会参考最近几天的日记聊天
4. 行为准则：App 退后台时自动分析你的喜好/作息，生成
   行为准则注入角色（隐私模式关闭）
5. 时空胶囊：在你常聊天的时段，每天最多推送 2 次来自日记
   的关心问候（通知带"聊聊"按钮）


九、设置说明
--------------------------------------------------------
【我的】->【设置】
- API Key：DeepSeek 密钥（仅存本机）
- 模型：deepseek-v4-flash（日常推荐）/ v4-pro
- 温度：0.2-1.8（低=冷静严谨，高=活泼随性）
- 思考模式：开启后更缜密但响应慢数倍（默认关）
- 显示思考过程：开启后展示推理过程（默认隐藏更像真人）
- 隐私模式：关闭自动分析，只保留你明确说"记住"的信息
- 时空胶囊：主动关心通知开关（默认开，有数据才推送）

【我的】->【外观】：浅色 / 深色 / 跟随系统


十、常见问题
--------------------------------------------------------
Q：提醒不触发？
A：确认已允许通知权限；OPPO/ColorOS 请在电池/后台管理
   中允许本应用后台运行。

Q：消息没回复或报错？
A：检查网络与 API Key 是否有效；思考模式下响应较慢属正常。

Q：费用是多少？
A：deepseek-v4-flash 约 ¥1/百万输入、¥2/百万输出，
   日常聊天费用极低，可先充值 ¥5 体验。

Q：换手机/清数据会丢什么？
A：角色、记忆、聊天记录均存本机，卸载应用即清空。
   建议定期导出重要聊天（多选 -> 导出）。

Q：应用被杀后时空胶囊/提醒可能不触发？
A：Android 后台限制所致，请允许自启动/后台运行；
   胶囊每日最多 2 次，避免骚扰。


十一、隐私说明
--------------------------------------------------------
- API Key 仅保存在本机，不会上传
- 对话内容会发送至 DeepSeek API 用于生成回复
- 记忆/日记/便签/收藏全部仅存本机
- 隐私模式可关闭所有自动分析
